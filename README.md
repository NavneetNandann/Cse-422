# Amazon Product Review Analytics

An academic Big Data Analytics project focused on analyzing Amazon
product reviews using Hadoop, Hive, Apache Spark, and Streamlit.

## Objectives
- Process product review datasets.
- Perform analytical queries.
- Explore big data processing techniques.
- Visualize analytical results.

## Technology Stack
- Python
- Hadoop
- Apache Hive
- Apache Spark
- Streamlit
